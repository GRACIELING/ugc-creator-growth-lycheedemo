# UGC 创作者成长任务系统 · Demo

横版手游风格的 UGC 玩法创作者成长任务系统交互 Demo，采用简约高品质设计风格。

## 在线预览

GitHub Pages 部署后访问：`https://<你的用户名>.github.io/ugc-creator-growth-demo/`

## 功能

- **成长阶段切换**：入驻建联 → 星手上路 → 新星闪耀 → 王牌创作 → 精英合伙人
- **页签切换**：任务 / 奖励 / 我的
- **任务领取交互**：点击「领取」实时累加星耀值并弹出提示
- **横版手游 UI**：毛玻璃顶/底栏、设备外壳、阶段进度与任务卡片

## 本地预览

直接用浏览器打开 `index.html` 即可，无需任何依赖。
